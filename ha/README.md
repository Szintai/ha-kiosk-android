# Home Assistant side

## Design versions (switch / roll back)

| | HA dashboard | card file | git tag |
|---|---|---|---|
| **v1** iOS dark, flat | `dashboard-kiosk/home` | `www/kiosk-cards.js` | `design-v1-ios-dark` |
| **v2** ambient (live backdrop, glass) | `dashboard-kiosk2/home` | `www/kiosk-cards-v2.js` | `design-v2-ambient` |

Both dashboards stay deployed side by side. The tablet shows whichever path is set in the app config
(Settings screen, or `adb shell am start -n hu.szintai.hakiosk/.MainActivity --es dashboard_path dashboard-kiosk/home`).
Rolling back = set the path back to `dashboard-kiosk/home` (v1). `python3 ha/scripts/deploy.py v1|v2|wake|tv|cam` re-deploys either one.

The kiosk app only renders a normal Lovelace dashboard (`dashboard-kiosk/home`). Everything
HA-specific lives here:

- `www/kiosk-cards.js` – custom cards `kiosk-weather` (current + 24 h + 7 days) and `kiosk-dock`
  (climate sparklines, lights, TV). Same `--o-*` design tokens as the `otthon-cards.js` dashboard.
- `dashboard/kiosk.json` – the dashboard config (weather entity, sensors, lights, TV pop-up).
- `www/kiosk-wake.js` – `kiosk-wake-tile` (today's wake-ups, screen awake/asleep, battery) and `kiosk-wake-chart` (modal: state +
  battery/charging, 24 h / 7 day bars, wake/dim log, on-demand camera). Data comes from `sensor.kiosk_tablet_wake_count`, a `total_increasing` counter the app reports through the
  HA `mobile_app` integration; every increase in the recorder history is one wake-up. `deploy.py wake` adds the tile and a
  Bubble Card pop-up (`#wakes`) to the Otthon dashboard.
- `automations/kiosk-tv-voice.json` – one automation with `conversation` triggers: Hungarian voice commands for the Samsung TV
  (on/off, volume +/-, *set volume to N* incl. spoken numbers, mute, channel, pause/play, YouTube, Netflix). Generated by
  `scripts/gen_tv_voice.py`, deployed with `deploy.py tv`; no configuration.yaml change or restart needed.
- **Tablet entities** (mobile_app, device "Kiosk Tablet"): `sensor.kiosk_tablet_wake_count`, `binary_sensor.kiosk_tablet_presence`,
  `sensor.kiosk_tablet_battery_level`, `binary_sensor.kiosk_tablet_battery_charging`, `sensor.kiosk_tablet_battery_temperature`,
  `sensor.kiosk_tablet_ip_address` (its attributes carry the camera URLs when sharing is on).
- **Camera:** the app can serve the front camera (`Kamerakép megosztása`, token-protected, only streams while a client is
  connected). `deploy.py cam` creates the `mjpeg` camera `camera.kiosk_tablet_camera` from the URL the tablet publishes; the
  modal's *Kamerakép megnyitása* button streams it through HA only while open.
- `scripts/deploy.py` – uploads the card, registers the resource and saves the dashboard.

```
HA_TOKEN=<long-lived token> python3 ha/scripts/deploy.py
```

Requires: Bubble Card (TV pop-up) and the `weather.home` entity (core *Open-Meteo* integration on the
home zone – gives a 7 day forecast; Met.no only returned 6).
